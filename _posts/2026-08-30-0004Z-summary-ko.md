## [텐센트, 재귀적 자기 개선 주장하는 Hy4 프리뷰 오픈소스 공개](https://www.tencent.com/tencent-releases-and-open-sources-tencent-hy4-preview/) ⭐️ 7.0/10

## [RAG 애플리케이션 접근 제어를 확인하는 오픈소스 도구](https://www.reddit.com/r/MachineLearning/comments/1w1zm5m/opensource_accesscontrol_checker_for/) ⭐️ 5.0/10

한 개발자가 rag-access-check라는 오픈소스 도구를 공개했습니다. 이 도구는 검색 증강 생성(RAG) 애플리케이션이 사용자가 접근 권한이 없는 문서를 검색하는지 확인합니다. 오프라인 테스트 케이스와 bearer token 또는 API key 인증을 사용한 실시간 HTTP API 테스트를 모두 지원합니다. RAG 애플리케이션이 기업 환경에서 점점 더 보편화됨에 따라, 검색된 문서가 사용자 권한을 준수하는지 확인하는 것이 보안과 규정 준수에 매우 중요합니다. 이 도구는 접근 제어 누출이 피해를 입히기 전에 이를 탐지하는 실용적이고 자동화된 방법을 제공합니다. 이 도구는 GitHub의 InfraGuard-Labs에 호스팅되어 있으며, 현재 초기 피드백 요청 단계에 있습니다. 실시간 HTTP API 테스트를 위해 bearer token 및 API key 인증을 지원하며, 라이브 서버 없이 오프라인 테스트 케이스를 실행할 수 있습니다.

reddit · r/MachineLearning · /u/Lostboy_journey · 8월 29일 22:11

**배경**: 검색 증강 생성(RAG)은 응답을 생성하기 전에 외부 지식 베이스에서 관련 정보를 검색하여 대규모 언어 모델(LLM)을 향상시키는 기술입니다. 이를 통해 LLM은 최신 데이터나 독점 데이터를 참조할 수 있지만, 보안 위험도 발생시킵니다. 접근 제어가 제대로 적용되지 않으면 사용자가 볼 권한이 없는 문서를 검색할 수 있습니다. Bearer token 인증은 클라이언트가 Authorization 헤더에 토큰(주로 JWT)을 제시하여 신원을 증명하는 일반적인 HTTP 인증 방법입니다.
