## [TypeSafe AI의 Jev: 텍스트 대신 확률을 출력하는 결정 모델](https://simonwillison.net/2026/Sep/21/jev/) ⭐️ 9.0/10

TypeSafe AI가 최초의 '시스템 원' 모델인 Jev를 공개했습니다. 이 모델은 텍스트 입력을 받지만 텍스트를 생성하는 대신 유형화된 확률적 결정(예/아니오, 선택, 점수 및 신뢰도)을 반환합니다. 입력 비용은 백만 토큰당 0.042달러에 불과하며 출력은 무료로, 기존 LLM보다 훨씬 저렴합니다. Jev는 의사 결정 작업에 최적화된 새로운 유형의 LLM으로, 분류, 우선순위 지정 및 점수 매기기 애플리케이션에서 기존 텍스트 기반 모델을 대체할 가능성이 있습니다. 극도로 낮은 비용과 빠른 속도는 소프트웨어 시스템에서 전례 없는 규모의 AI 기반 결정을 가능하게 할 수 있습니다. Jev는 세 가지 질문 유형을 지원합니다: 베르누이(예/아니오, 0-1 점수 반환), 선택(옵션 중 하나 선택, 확률 분포 포함), 점수(설명된 범위를 따라 숫자 수준 부여). 질문은 병렬로 평가되며, API는 단일 '상태' 문서와 여러 질문을 한 번의 호출로 처리합니다.

## [Cloudflare Python Workers, Pyodide/WebAssembly 기반으로 정식 출시](https://simonwillison.net/2026/Sep/21/cloudflare-python-worker/) ⭐️ 8.0/10

2년간의 프리뷰 기간을 마치고 Cloudflare는 Python이 이제 Workers 플랫폼에서 일급(first-class)으로 완전히 지원되는 언어라고 발표했습니다. 구현 방식은 Pyodide를 통해 Python을 WebAssembly로 컴파일한 뒤 V8 기반 workerd 런타임에서 실행하는 것입니다. 이는 서버리스 컴퓨팅의 중요한 이정표로, Python 개발자들이 Cloudflare 엣지 네트워크에 안정적이고 프로덕션 준비가 된 방식으로 배포할 수 있는 경로를 제공합니다. 또한 이번 릴리스에는 Pyodide 핵심 유지보수자 두 명이 참여해 Cloudflare의 Python 생태계에 대한 중대한 투자를 보여줍니다. WebAssembly VM에서 multiprocessing과 threading이 모두 작동하지 않아 일부 동시성 워크로드가 제한됩니다. 로컬 개발에는 pywrangler 도구(PyPI에서는 workers-py로 배포)를 사용하며, 123MB 크기의 workerd 바이너리 안에서 V8 내 WebAssembly로 Pyodide 코드를 실행하는 전체 로컬 시뮬레이션을 수행합니다.

rss · Simon Willison · 9월 21일 22:25

**배경**: Cloudflare Workers는 Chrome의 JavaScript 엔진인 V8에서 실행되는 서버리스 엣지 컴퓨팅 플랫폼입니다. Pyodide는 CPython을 WebAssembly로 포팅하는 프로젝트로, Python을 브라우저 및 기타 WebAssembly 환경에서 실행할 수 있게 해줍니다. Cloudflare는 이 둘을 결합해 JavaScript Workers를 지원하는 동일한 엣지 인프라에서 Python 코드를 실행하되, 네이티브 스레드 부재와 같은 WebAssembly 실행의 고유한 제약을 수용합니다.

## [프로토타입 기반 학습기가 로컬 LLM이 역전파 없이 즉시 사실을 학습하게 한다](https://www.reddit.com/r/MachineLearning/comments/1wmn76r/i_built_a_frameworkfree_prototype_learner_that/) ⭐️ 7.0/10
