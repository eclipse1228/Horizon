## [뮌헨시, libexpat 유지보수자에게 6개월 오픈소스 안식년 지원](https://blog.hartwork.org/posts/libexpat-city-of-munich-open-source-sabbatical/) ⭐️ 7.0/10

## [Bad Apple 비디오를 3MB 신경망으로 압축](https://www.reddit.com/r/MachineLearning/comments/1vfrco1/i_compressed_bad_apple_into_a_3mb_neural_network_p/) ⭐️ 7.0/10

한 개발자가 사인 활성화 함수(SIREN)를 사용하는 소형 다층 퍼셉트론(MLP)을 훈련시켜 Bad Apple 애니메이션 전체를 기억하게 했으며, 약 27억 픽셀을 단 79만 개의 매개변수(float32 기준 3.2MB)로 압축했습니다. 이 네트워크는 3차원 좌표(시간, y, x)를 입력받아 회색조 픽셀 값을 출력함으로써 비디오를 가중치에 암시적으로 저장합니다. 이 프로젝트는 암시적 신경 표현(INR)을 비디오 압축에 실용적으로 적용하여 합리적인 시각적 품질로 높은 압축률을 달성했음을 보여줍니다. 또한 시간 스트레칭 및 움직임 중심 샘플링과 같은 효과적인 훈련 기법이 시간적 데이터를 처리할 때 SIREN 네트워크의 일반적인 한계를 극복하는 방법을 강조합니다. 네트워크는 사인 활성화 함수를 사용하는 5개의 선형 레이어, 512개의 은닉 유닛, ω₀=30, 시그모이드 출력을 사용합니다. 원본 비디오는 1620프레임, 384×384 해상도로 서브샘플링되었으며, 시간 좌표는 공간에 비해 4배 확장되어 시간적 용량을 향상시켰습니다. 각 훈련 배치의 절반은 인접 프레임 간에 변경된 픽셀에서 추출되었습니다.

reddit · r/MachineLearning · /u/Which_Lie_8932 · 8월 5일 00:01

**배경**: 암시적 신경 표현(INR)은 이미지, 오디오 또는 비디오와 같은 연속 신호를 다층 퍼셉트론(MLP)의 가중치로 직접 매개변수화하는 신경망 클래스입니다. SIREN(사인파 표현 네트워크)은 기존의 ReLU 대신 주기적인 사인 활성화 함수를 사용하여 네트워크가 고주파 세부 정보를 더 효과적으로 표현할 수 있게 합니다. 또 다른 일반적인 접근 방식은 푸리에 특징 매핑을 사용하여 MLP가 고주파 함수를 학습하도록 돕는 것입니다. 이 프로젝트는 INR 기술을 비디오 압축에 적용하여 전체 애니메이션을 소형 네트워크에 암시적으로 저장합니다.

## [브라우저 창 기준 div 중앙 정렬: CSS 실험 논란](https://seg6.space/posts/center-div/) ⭐️ 6.0/10

seg6.space의 기술 블로그 게시물은 div를 뷰포트가 아닌 전체 브라우저 창을 기준으로 중앙 정렬하는 CSS/JavaScript 기법을 소개한다. 커뮤니티 테스트 결과 Firefox와 Edge에서 특히 사이드바가 열렸을 때 일관되지 않게 동작하며 콘텐츠가 어긋나거나 가려지는 문제가 나타난다. 이 주제는 틈새이지만 실제 존재하는 프런트엔드 문제를 다룬다. 브라우저 UI 사이드바(북마크, 세로 탭)는 실제 뷰포트를 줄이는데, 대부분의 CSS 중앙 정렬은 이를 고려하지 않는다. 커뮤니티 논의는 이런 '영리한' 우회책이 실제로 자주 실패하는 이유를 보여주며, 표준적이고 예측 가능한 레이아웃 방식에 대한 업계 추세를 재확인시켜 준다. 이 기법은 브라우저가 뷰포트 너머의 창 크기를 보고해 주는 것에 의존하며, 렌더링 후 JavaScript로 조정하기 때문에 눈에 띄는 깜빡임이 발생한다. 테스트 결과 사이드바가 콘텐츠를 가리거나 콘텐츠가 화면 밖으로 밀려나는 등 무작위적인 동작이 관찰됐고, Firefox와 Edge(고정형 및 자동 접이식 사이드바 포함)에 따라 결과가 달랐다.

hackernews · seg6 · 8월 4일 22:24 · [토론](https://news.ycombinator.com/item?id=49176055)

**배경**: div 중앙 정렬은 고전적인 CSS 과제로, 보통 flexbox(justify-content/align-items), CSS grid, 또는 절대 위치 지정과 transform: translate(-50%, -50%) 조합으로 해결한다. 일반적으로 요소는 뷰포트(브라우저 창 안의 보이는 영역)를 기준으로 중앙 정렬된다. 그러나 북마크 사이드바나 세로 탭 같은 브라우저 UI 요소는 그 보이는 영역을 줄이며, 이 글은 대부분의 CSS 레이아웃이 무시하는 요소를 감안해 요소를 전체 브라우저 창 기준으로 중앙 정렬하려고 시도한다.
