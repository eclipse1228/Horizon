## [EVE Online, 240만 줄의 Python 2.7 코드를 Python 3로 마이그레이션 시작](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 7.0/10

EVE Online이 240만 줄의 Stackless Python 2.7 코드를 Python 3로 마이그레이션하기 시작했다고 발표했습니다. futurize 스크립트를 사용한 후 Python 2와 3 간의 약 2만 개 동작 차이를 수동으로 검토할 예정입니다. 이번 마이그레이션은 가장 오래 운영된 대규모 Python 코드베이스 중 하나에 대한 획기적인 기술 작업으로, 여전히 Python 2에 머물러 있는 다른 프로젝트에 귀중한 교훈을 제공합니다. 또한 현재 중단된 Stackless Python 인터프리터에서 벗어나는 어려움을 강조합니다. 마이그레이션은 futurize 스크립트를 사용하여 코드를 자동 변환한 후, Python 2와 3의 동작 차이가 있는 약 2만 곳(예: 정수 나눗셈, Python 2에서 1/2 = 0, Python 3에서 0.5)을 수동으로 처리합니다. 발표에서는 Stackless Python을 대체할 방법을 자세히 설명하지 않았지만, 이전에 EVE Frontier에서 carbonengine/scheduler 라이브러리를 사용한 솔루션을 발표한 바 있습니다.

rss · Simon Willison · 8월 25일 22:59

**배경**: EVE Online은 2003년 출시 이후 Stackless Python에서 실행되어 왔으며, 마지막 주요 업그레이드는 2010년 Stackless Python 2.7이었습니다. Stackless Python은 운영 체제 스레드의 오버헤드 없이 동시성을 제공하는 마이크로스레드(태스크렛)를 제공하는 CPython의 수정 버전입니다. 이 프로젝트는 2025년 2월에 공식 중단되었으며 GitHub 저장소가 보관되어 마이그레이션이 시급해졌습니다. futurize 스크립트는 Python 2 코드를 Python 3로 변환하면서 Python 2와의 호환성을 위한 임포트를 추가하는 자동화 도구입니다.

## [scikit-learn BayesianRidge 불확실성 계산 버그 수정](https://www.reddit.com/r/MachineLearning/comments/1vym6cn/catching_bugs_in_scikitlearn_d/) ⭐️ 6.0/10

Reddit 게시물이 scikit-learn 1.8과 1.9 버전을 비교하는 노트북을 공유하며, BayesianRidge의 불확실성 계산에서 버그 수정을 밝혀냈습니다. 이 수정은 모델이 예측 불확실성을 계산하는 방식을 바로잡아 신뢰 구간의 신뢰성을 향상시킵니다. 이 수정은 BayesianRidge가 과학 연구 및 위험 평가와 같이 불확실성 정량화가 중요한 회귀 작업에 널리 사용되기 때문에 중요합니다. 이 수정은 사용자가 더 정확한 신뢰 구간을 얻어 더 나은 정보에 기반한 결정을 내릴 수 있도록 보장합니다. 노트북은 두 버전에서 predict 메서드를 추적하여 정확한 공식 변경을 식별합니다. 이 버그는 예측 불확실성을 추정하는 데 사용되는 사후 분산 계산에 영향을 미쳤을 가능성이 높습니다.

reddit · r/MachineLearning · /u/Lost-Dragonfruit-663 · 8월 26일 03:57

**배경**: BayesianRidge는 베이지안 추론을 통합하여 회귀 계수뿐만 아니라 그 불확실성도 추정하는 선형 회귀 모델입니다. 이는 모델이 예측에 대해 가지는 신뢰도를 반영하는 예측 구간을 제공하며, 불확실성 하에서 의사 결정에 유용합니다. 이 버그 수정은 이러한 구간이 올바르게 계산되도록 보장하여 모델의 신뢰성을 향상시킵니다.
