## [폰트 신경망 임베딩이 tSNE를 통해 꽃 모양 구조를 드러내다](https://www.reddit.com/r/MachineLearning/comments/1wypbnf/embedding_every_font_with_neural_networks_makes/) ⭐️ 7.0/10

이 프로젝트는 사전 훈련된 신경망을 사용하여 각 폰트의 모든 글리프를 고차원 벡터로 임베딩한 후, tSNE를 적용해 XYZ 및 RGB 채널로 차원을 축소하여 시각화합니다. Google Fonts의 결과 지도는 예상치 못하게 꽃 모양 구조를 형성했으며, 필기체 폰트들이 수술(stamen) 영역에 모였습니다. 이 작업은 폰트 유사성 검색을 위한 새롭고 직관적인 접근 방식을 보여주며, 전통적인 분류로는 명확하지 않은 폰트 디자인의 잠재적 구조를 드러냅니다. 또한 신경망 임베딩과 비선형 차원 축소의 결합이 창의적이고 탐색적인 데이터 분석에 얼마나 강력한지 보여줍니다. 저자는 맞춤형 사전 훈련 신경망을 사용하여 각 폰트의 임베딩을 생성하고, tSNE, PCA, UMAP을 비교한 결과 tSNE가 가장 좋은 구조를 생성함을 발견했습니다. 대화형 지도는 font-search.com/map에서 볼 수 있으며, 코드 저장소(GitHub)는 다소 정리되지 않은 상태입니다.

reddit · r/MachineLearning · /u/Chroma-Crash · 10월 6일 00:51

**배경**: 신경망 임베딩은 대규모 데이터셋에서 학습된 밀집 벡터 표현으로, 데이터의 의미적 또는 시각적 특징을 포착합니다. tSNE(t-분포 확률적 이웃 임베딩)는 고차원 데이터를 2차원 또는 3차원으로 매핑하여 시각화하는 비선형 차원 축소 기법으로, 국소 구조를 보존합니다. PCA와 UMAP은 대안적인 방법으로, PCA는 선형이고 UMAP은 일반적으로 더 빠르지만 tSNE는 더 복잡한 패턴을 드러낼 수 있습니다.

## [Example.com, 수십 년 만의 대대적인 리디자인으로 Hyrum의 법칙 논쟁 촉발](https://www.debugbear.com/blog/example-dot-com-redesign-history) ⭐️ 6.0/10

Example.com, 문서화와 테스트에 널리 사용되는 표준 예제 도메인이 수십 년 만에 처음으로 대대적인 시각적 리디자인을 단행했습니다. 이 변경으로 인해 이전 레이아웃에 의존하던 많은 자동화 테스트가 깨지면서 Hyrum의 법칙이 실제로 입증되었습니다. 이 사건은 시스템의 문서화되지 않거나 우연적인 측면에 의존하는 자동화 테스트의 취약성을 부각시킵니다. 이는 API의 모든 관찰 가능한 동작이 의도되지 않았더라도 결국 의존하게 된다는 Hyrum의 법칙을 실질적으로 상기시켜 줍니다. 리디자인에서는 이전에 모든 언어를 표시하던 점진적 불투명도 전환을 제거했으며, 이제 페이지는 CSS 애니메이션 없이 언어를 바로 보여줍니다. 사소한 예제 사이트임에도 불구하고, 이 변경은 정확한 HTML 구조에 의존하던 수많은 자동화 테스트를 깨뜨렸습니다.

**배경**: Hyrum의 법칙은 소프트웨어 공학 격언으로, API 사용자가 충분히 많아지면 의도하지 않은 모든 관찰 가능한 동작조차 의존하게 된다는 것입니다. 자동화 UI 테스트는 특정 DOM 요소, CSS 클래스 또는 레이아웃 세부 사항에 의존하는 경우가 많아 특히 취약하며, 이러한 세부 사항은 예고 없이 변경될 수 있습니다. Example.com은 IANA가 문서 예제용으로 예약한 도메인으로, 이번 리디자인 전까지 수십 년 동안 거의 변경되지 않았습니다.
