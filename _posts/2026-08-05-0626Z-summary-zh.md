## [LLM 0.32：推理痕迹、服务端工具与 OpenAI 响应支持](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32 是开源命令行工具的一次重大更新，新增了模型推理痕迹的可视化显示、服务端提供商工具（如 OpenAI 的 CodeInterpreter 和 WebSearch）、重新设计的内容可寻址 SQLite 日志，以及对 OpenAI Responses API 和 GPT-5.6 模型系列的支持。 此版本显著提升了 LLM 用户的透明度和实用性，允许他们检查模型的推理过程，并直接从命令行利用代码执行和网络搜索等服务端功能。它还使 LLM 成为 AI 从业者更强大、更灵活的工具，集成了前沿的 API 特性。 推理痕迹默认输出到标准错误流，并可通过 -R/--hide-reasoning 标志隐藏。新的默认模型是 GPT-5.6 Luna，而 `llm openai endpoint` 命令允许针对任何兼容 OpenAI 的端点执行一次性提示，且不记录日志。llm-anthropic 插件新增了 WebSearch、WebFetch、CodeExecution 和 AnthropicMCP 工具。

## [将 Bad Apple 视频压缩成 3MB 神经网络](https://www.reddit.com/r/MachineLearning/comments/1vfrco1/i_compressed_bad_apple_into_a_3mb_neural_network_p/) ⭐️ 7.0/10

一位开发者训练了一个使用正弦激活函数（SIREN）的小型多层感知机（MLP），使其记住整个 Bad Apple 动画，将约 27 亿像素压缩到仅 79 万个参数（float32 格式下 3.2 MB）。该网络接收三维坐标（时间、y、x）并输出灰度像素值，从而将视频隐式存储在权重中。 该项目展示了隐式神经表示（INR）在视频压缩中的实际应用，以合理的视觉质量实现了高压缩比。它还突出了有效的训练技巧——如时间拉伸和运动聚焦采样——这些技巧克服了 SIREN 网络在处理时间数据时的常见限制。 该网络使用 5 个带有正弦激活的线性层，512 个隐藏单元，ω₀=30，以及 sigmoid 输出。原始视频被下采样至 1620 帧、384×384 分辨率，时间坐标相对于空间坐标放大了 4 倍以提高时间容量；每个训练批次的一半像素来自相邻帧之间发生变化的区域。

reddit · r/MachineLearning · /u/Which_Lie_8932 · 8月5日 00:01

**背景**: 隐式神经表示（INR）是一类神经网络，它们将图像、音频或视频等连续信号直接参数化为多层感知机（MLP）的权重。SIREN（正弦表示网络）使用周期性的正弦激活函数代替传统的 ReLU，使网络能够更有效地表示高频细节。另一种常见方法是使用傅里叶特征映射来帮助 MLP 学习高频函数。该项目将 INR 技术应用于视频压缩，将整个动画隐式存储在一个小型网络中。

## [让 div 相对浏览器窗口居中：CSS 实验引发争议](https://seg6.space/posts/center-div/) ⭐️ 6.0/10

seg6.space 上的一篇技术博客介绍了一种让 div 相对于整个浏览器窗口（而非视口）居中的 CSS/JavaScript 技巧。社区测试发现，该技巧在 Firefox 和 Edge 中表现不一致，尤其在打开侧边栏时会导致内容错位或被遮挡。 这涉及一个真实但小众的前端问题：浏览器自带的侧边栏（如书签、垂直标签页）会缩小实际视口，而大多数 CSS 居中方法并不会考虑这一点。社区的讨论揭示了这类“巧妙”变通方案在实践中为何经常失效，也印证了业界对标准、可预测布局方法的重视。 该技术依赖于浏览器报告超出视口的窗口尺寸，并在渲染后用 JavaScript 进行调整，因此会出现明显的闪烁。测试者发现其行为随机：有时侧边栏遮住内容，有时内容移出屏幕，而且 Firefox 与 Edge（包括固定与自动折叠侧边栏）的表现各不相同。

hackernews · seg6 · 8月4日 22:24 · [社区讨论](https://news.ycombinator.com/item?id=49176055)

**背景**: 让 div 居中是一个经典的 CSS 难题，通常用 flexbox（justify-content/align-items）、CSS grid 或绝对定位加 transform: translate(-50%, -50%)来解决。正常使用时，元素是相对于视口（即浏览器窗口内的可见区域）居中的。而浏览器 UI 元素如书签侧边栏或垂直标签页会缩小可见区域；这篇文章则试图让元素相对于整个浏览器窗口居中，这是大多数 CSS 布局不会考虑的区别。
