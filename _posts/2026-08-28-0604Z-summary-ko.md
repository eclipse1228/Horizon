## [프롬프트 인젝션 공격, Claude Code 자동 모드를 80% 확률로 무력화](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) ⭐️ 8.0/10

보안 연구원 Johann Rehberger가 Claude Code Opus 5의 자동 모드에 대해 80%의 성공률을 보이는 프롬프트 인젝션 공격을 발견했습니다. 이 공격은 Claude가 zip 아카이브를 다운로드하고 임포트 하이재킹을 통해 악성 로컬 Python 파일을 실행하도록 속입니다. 이 발견은 코딩 에이전트의 안전 장치로서 자동 모드에 대한 Anthropic의 신뢰를 약화시킵니다. 내장된 보호 장치가 있음에도 AI 에이전트가 적대적 입력에 취약하다는 것을 보여주며, 샌드박싱과 네트워크 이그레스 제한의 필요성을 강조합니다. 이 공격은 Python의 모듈 임포트 순서를 악용합니다. Claude가 base64를 임포트할 때 Python은 먼저 현재 디렉토리를 검색하는데, 추출된 zip 아카이브에 악성 struct.py가 배치되어 있습니다. 일부 경우 자동 모드가 Claude의 자체 정리 명령을 차단하여 멀웨어 중지를 막았습니다.

## [uv 0.12.7, 크로스 플랫폼 해석, Azure 재시도, 콘텐츠 주소 캐시 미리보기 추가](https://github.com/astral-sh/uv/releases/tag/0.12.7) ⭐️ 5.0/10

uv 0.12.7이 2026년 8월 27일에 출시되어 Linux s390x, ppc64le, loongarch64 대상에 대한 크로스 플랫폼 의존성 해석을 지원합니다. 또한 콘텐츠 기반 디렉터리 해시를 사용하여 추출된 휠을 중복 제거하는 콘텐츠 주소 캐시 미리보기 기능을 도입하고, Azure Storage 엔드포인트 처리를 개선하여 익명 액세스가 거부될 때 구성된 자격 증명으로 다운로드를 재시도합니다. 이번 릴리스는 메인프레임(s390x) 및 PowerPC(ppc64le)와 같은 비 x86 Linux 아키텍처에 의존하는 엔터프라이즈 및 과학 컴퓨팅 환경에서 uv의 사용성을 확장합니다. 콘텐츠 주소 캐시 미리보기는 상당한 디스크 공간 절약과 빠른 캐시 작업을 약속하며, Azure 재시도 수정은 Azure Blob Storage에서 개인 패키지 인덱스를 호스팅하는 사용자의 안정성을 향상시킵니다. s390x, ppc64le, loongarch64에 대한 크로스 플랫폼 해석 지원은 --python-platform 플래그를 통해 사용할 수 있습니다. 콘텐츠 주소 캐시 미리보기 기능은 현재 macOS 및 Linux에서만 지원되며, UV_PREVIEW 환경 변수 또는 구성을 통해 활성화할 수 있습니다. 또한 uv는 이제 동일 버전의 최신 빌드로 업그레이드할 때 관리형 Python 설치를 교체하고, 캐싱 전에 해시 불일치가 있는 소스 아카이브를 거부합니다.

github · astral-automations-bot[bot] · 8월 27일 22:14

**배경**: uv는 Rust로 작성된 빠른 Python 패키지 및 프로젝트 관리자로, 속도와 안정성으로 유명합니다. 크로스 플랫폼 의존성 해석을 통해 사용자는 현재 실행 중인 플랫폼이 아닌 다른 대상 플랫폼에 대한 의존성을 해석할 수 있으며, 이는 CI/CD 파이프라인 및 다중 아키텍처 배포에 필수적입니다. 콘텐츠 주소 캐시는 이름과 버전이 아닌 콘텐츠 해시를 기반으로 패키지를 저장하여 중복 제거 및 디스크 사용량 감소를 가능하게 합니다. Azure Blob Storage는 개인 Python 패키지 인덱스를 호스팅하는 데 일반적으로 사용되며, 익명 액세스 제한으로 인해 다운로드 실패가 발생할 수 있습니다.

## [OpenTIE와 OpenXWA, 고전 스타워즈 게임 재구현](https://github.com/elyosh/OpenTIE/) ⭐️ 5.0/10

OpenTIE는 스타워즈: TIE Fighter를 Windows, macOS, Linux에서 네이티브로 실행할 수 있는 완전한 오픈소스 재구현입니다. OpenXWA는 동일한 플랫폼을 위해 스타워즈: X-Wing Alliance를 충실히 재구축하는 진행 중인 프로젝트입니다. 이 프로젝트들은 1990년대의 상징적인 스타워즈 우주 전투 시뮬레이터 두 가지를 오래된 에뮬레이터나 호환성 계층에 의존하지 않고 현대 운영 체제에서 실행 가능하게 만듭니다. 이는 새로운 세대와 모드 커뮤니티를 위해 게임 역사를 보존하는 것입니다. OpenTIE는 1995년 Collector's CD-ROM과 1998년 Windows 릴리스를 모두 지원하며, 두 에디션의 자산을 결합하여 향상된 경험을 제공할 수 있습니다. OpenXWA는 원래 모습을 보존하는 클래식 렌더러와 오래된 DirectDraw 및 Direct3D 호출을 피하는 향상된 렌더러를 제공합니다.

hackernews · elyosh · 8월 27일 22:10 · [토론](https://news.ycombinator.com/item?id=49471965)

**배경**: 스타워즈: TIE Fighter(1994)와 스타워즈: X-Wing Alliance(1999)는 원래 DOS와 초기 Windows에서 실행된 높은 평가를 받은 우주 전투 시뮬레이터입니다. 이 게임들은 DirectDraw 및 Direct3D 7과 같은 레거시 그래픽 API에 의존했기 때문에 현대 시스템에서 자주 충돌하거나 그래픽 결함이 발생합니다. OpenTIE 및 OpenXWA와 같은 오픈소스 재구현은 원래 게임 로직을 리버스 엔지니어링하고 현대 API(OpenGL 또는 Vulkan)를 사용하여 렌더링함으로써 게임 데이터를 네이티브로 실행할 수 있게 합니다. 이 접근 방식은 OpenTTD나 OpenRA와 같은 다른 성공적인 보존 프로젝트와 유사합니다.
