Chromium 기반 브라우저 사용자는 악성 웹페이지의 무단 코드 실행을 방지하기 위해 즉시 업데이트해야 합니다. Google은 이 취약점을 윤리적으로 신고한 연구원에게 1,000달러의 버그 바운티를 지급한 것으로 알려졌으나, 이미 실제 환경에서 악용되고 있습니다. 이 취약점은 모든 Chromium 버전에 영향을 미치며, Chrome, Edge, Brave 및 GrapheneOS의 Vanadium 등 브라우저에서 패치가 배포되고 있습니다.

## [Rust 기반 React 컴파일러, Vite에 네이티브 통합](https://blog.master.dev/react-now-rusted-all-the-way-out/) ⭐️ 8.0/10

Rust 기반 React 컴파일러인 OXC(JavaScript Oxidation Compiler)가 이제 Vite에 네이티브로 통합되어 빌드 파이프라인에서 Babel을 대체합니다. 이를 통해 Vite를 사용하는 React 애플리케이션에서 Babel 변환이 필요 없게 됩니다. 이 통합은 Babel의 JavaScript 기반 변환을 Rust 기반 변환으로 대체하여 빌드 성능을 크게 향상시키며, 최대 20배까지 빨라질 수 있습니다. Vite를 사용하는 React 개발자에게 툴체인을 단순화하고 구성 오버헤드를 줄이며 개발 주기를 가속화합니다. OXC 통합은 @vitejs/plugin-react-oxc 플러그인을 통해 제공되며, Oxc의 Rust 기반 툴체인을 활용하여 변환을 수행합니다. 또한 컴포넌트와 훅의 자동 메모이제이션을 위한 실험적 React Compiler 기능을 지원합니다.

**배경**: Vite는 네이티브 ES 모듈을 사용하여 빠른 개발을 지원하는 최신 빌드 도구이지만, 전통적으로 JSX 및 최신 JavaScript 트랜스파일을 위해 Babel에 의존했습니다. OXC(JavaScript Oxidation Compiler)는 Rust 기반 툴체인으로, Babel 및 TypeScript 컴파일러와 같은 JavaScript 기반 도구를 더 빠른 Rust 대안으로 대체하는 것을 목표로 합니다. React Compiler는 컴포넌트를 자동으로 메모이제이션하여 리렌더링을 최적화하는 새로운 실험적 기능입니다.
