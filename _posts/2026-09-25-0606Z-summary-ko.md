## [uv 0.12.19 릴리스: PyPy 및 GraalPy 업데이트와 미리보기 기능 추가](https://github.com/astral-sh/uv/releases/tag/0.12.19) ⭐️ 5.0/10

uv 0.12.19는 PyPy 3.11.16 및 3.12.14를 추가하고 GraalPy를 빌드 25.4.4로 업데이트하며, CPython 3.15 이상에서 지연 임포트(lazy imports)와 해석 입력(resolution inputs)에 대한 미리보기 기능을 도입하고 여러 버그를 수정했습니다. 이번 릴리스는 uv가 PyPy와 GraalPy 같은 대체 Python 런타임을 지원하고, Python 3.15의 지연 임포트와 같은 기능을 선제적으로 도입하여 시작 성능을 향상시키며, 패키지 해석 및 잠금 파일 관리의 신뢰성을 개선함을 보여줍니다. 지연 임포트 미리보기 기능은 CPython 3.15 이상이 필요하며 `build-lazy-imports` 미리보기 플래그로 활성화됩니다. 해석 입력 기능은 사용되지 않는 해석 설정을 uv.lock에서 생략하여 잠금 파일 신선도 검사를 더 효율적으로 만듭니다.

github · astral-releases-bot[bot] · 9월 25일 00:33

**배경**: uv는 Astral이 개발한 Rust 기반의 빠른 Python 패키지 관리자입니다. PyPy는 JIT 컴파일러를 갖춘 대체 Python 구현이며, GraalPy는 GraalVM 위에 구축된 Python 런타임으로 Java 통합을 지원합니다. 지연 임포트는 모듈 로딩을 처음 사용할 때까지 미루어 시작 시간을 줄일 수 있습니다. 해석 입력 기능은 잠금 파일이 최신인지 확인할 때 사용되지 않는 해석 설정의 변경을 무시할 수 있게 합니다.
