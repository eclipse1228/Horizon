## [버그 블라인드니스: 개발자가 명백한 오류를 놓치는 이유](https://danluu.com/bug-blind/) ⭐️ 8.0/10

Dan Luu의 글 'Bug Blindness'는 개발자의 정신 모델이 시스템과 너무 밀접하게 정렬되어 테스트와 디버깅에서 사각지대를 만들어 버그를 발견하지 못하는 이유를 탐구합니다. 이 인지 편향은 업계 전반의 소프트웨어 품질에 영향을 미쳐 사용자를 좌절시키고 유지보수 비용을 증가시키는 지속적인 버그로 이어집니다. 이 글은 버그 블라인드니스가 개발자의 정신 모델이 시스템과 너무 정렬되어 둘 다 동일한 사각지대를 공유하여 시스템의 논리 밖에서 생각하기 어렵게 만드는 데서 비롯된다고 강조합니다.

hackernews · davidmckenna · 8월 30일 00:21 · [토론](https://news.ycombinator.com/item?id=49494520)

**배경**: 버그 블라인드니스는 개발자의 시스템에 대한 정신 모델이 실제 동작과 너무 밀접하게 정렬되어 명백한 오류를 간과하는 인지 편향입니다. 이는 집중된 주의로 인해 예상치 못한 자극을 인지하지 못하는 '주의맹(inattentional blindness)'과 대조됩니다. 소프트웨어 개발에서 이는 원래 개발자에게는 보이지 않지만 다른 사람에게는 명백한 지속적인 버그로 이어질 수 있습니다.

## [텐센트, Hy4 Preview 오픈소스 공개: 770B MoE LLM, 100만 토큰 컨텍스트](https://simonwillison.net/2026/Aug/29/hy4/) ⭐️ 8.0/10

텐센트가 Hy4 Preview를 출시했습니다. 이는 7700억 개의 총 파라미터, 490억 개의 활성 파라미터, 100만 토큰 컨텍스트 윈도우를 갖춘 오픈 웨이트 대규모 언어 모델로, Hugging Face에 1.56TB 크기로 제공됩니다. 이전 Hy3 모델(2950억 총 파라미터, 210억 활성 파라미터)에 비해 상당한 규모 확장입니다. 이번 릴리스는 오픈 웨이트 LLM을 크게 발전시켜, 실제 생산성 및 과학 작업에서 경쟁력 있는 성능을 갖춘 거대 7700억 파라미터 모델을 제공합니다. 텐센트의 주요 릴리스로서, 독점 모델에 대한 강력하고 접근 가능한 대안을 제시함으로써 오픈소스 AI 환경에 영향을 미칠 수 있습니다. Hy4 Preview는 MoE(Mixture-of-Experts) 아키텍처를 사용하며 총 7700억 개, 활성 490억 개의 파라미터를 갖고, Apache 2.0 오픈소스 라이선스로 제공되며 입력 토큰당 $0.834/M, 출력 토큰당 $2.501/M입니다. chat_template.jinja 파일을 통해 'high'와 'no_think' 두 가지 추론 노력 수준을 지원하며, OpenRouter에서 SVG 생성 프롬프트로 테스트되었습니다.

## [RAG 시스템의 문서 접근 누출을 확인하는 오픈소스 도구](https://www.reddit.com/r/MachineLearning/comments/1w1zm5m/opensource_accesscontrol_checker_for/) ⭐️ 6.0/10

새로운 오픈소스 도구인 rag-access-check가 출시되어, 검색 증강 생성(RAG) 애플리케이션이 사용자가 접근해서는 안 되는 문서를 의도치 않게 검색하는지 테스트합니다. 이 도구는 오프라인 테스트 케이스와 Bearer Token 또는 API 키 인증을 사용한 실시간 HTTP API 테스트를 지원합니다. 많은 엔터프라이즈 RAG 시스템에는 검색이 권한을 인식하지 못해 민감한 문서가 유출될 수 있는 알려진 접근 제어 격차가 있습니다. 이 도구는 배포 전에 이러한 누출을 감지하는 간단한 방법을 제공함으로써 중요한 보안 문제를 해결합니다. 이 도구는 오픈소스이며 GitHub의 InfraGuard-Labs/rag-access-check 저장소에 호스팅되어 있습니다. 현재 초기 단계에 있으며, 작성자는 엔지니어들이 비민감 환경에서 테스트하고 피드백을 제공해 주기를 요청하고 있습니다.

reddit · r/MachineLearning · /u/Lostboy_journey · 8월 29일 22:11

**배경**: 검색 증강 생성(RAG)은 대규모 언어 모델(LLM)을 외부 지식 베이스에 연결하여 실시간으로 관련 문서를 가져올 수 있게 하는 기술입니다. 그러나 RAG 시스템의 일반적인 결함은 검색이 사용자 권한이 아닌 의미적 유사성에 기반하기 때문에 사용자가 볼 권한이 없는 문서를 받을 수 있다는 점입니다. 이러한 접근 제어 격차는 데이터 유출로 이어질 수 있으며, 엔터프라이즈 배포에서 알려진 보안 문제입니다.
