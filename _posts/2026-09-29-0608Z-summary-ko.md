## [Anthropic, 더 빠르고 저렴하고 강력해진 Claude Sonnet 5.5 출시](https://simonwillison.net/2026/Sep/28/claude-sonnet-5-5/) ⭐️ 7.0/10

Anthropic가 새로운 중간급 모델인 Claude Sonnet 5.5를 출시했다. 이 모델은 30% 이상 빠르게 실행되고 대부분의 작업 비용이 최대 30% 저렴하지만 가격은 Sonnet 5와 동일하다. 모든 벤치마크에서 Sonnet 5를 능가하며 이제 claude.ai 무료 티어에서도 사용된다. 이번 출시는 LLM 시장의 경쟁을 심화시킨다. Anthropic의 무료 티어가 이제 OpenAI ChatGPT 무료 티어(루나 5.6 사용)보다 훨씬 더 강력한 모델을 제공하기 때문이다. 낮은 비용, 빠른 속도, Opus에 가까운 코딩 성능의 조합은 개발자와 소비자의 선택을 바꿀 수 있다. Sonnet 5.5는 Opus 5.5와 동일한 'max' 사고 강도 버그를 보인다. 펠리컨 렌더링 테스트에서 128,000개 토큰(1.28달러)을 소진한 후 실패했다. 'xhigh' 강도에서는 41초 만에 올바른 SVG를 생성했으며 비용은 5.74센트였다. Anthropic은 Haiku 5.5가 '몇 주 내' 출시될 것이라고 밝혔다.

**배경**: Claude의 'effort'(사고 강도) 매개변수는 모델이 응답할 때 사용하는 토큰 수를 제어하며, 응답의 철저함과 토큰 효율성 사이에서 균형을 맞춘다. 'Thinking'(추론)은 별도의 설정으로, Claude가 응답 전에 더 많은 시간을 들여 계획할 수 있게 하며 두 설정을 함께 사용할 수 있다. 'max' 사고 강도 설정은 토큰을 매우 많이 소비하여 복잡한 생성 작업에서 컨텍스트 창을 고갈시킬 수 있는데, 이는 Opus 5.5에서도 발견된 버그다.

## [uv 0.12.20 출시: 잠금 파일 재사용 개선 및 pylock.toml 미리 보기 기능](https://github.com/astral-sh/uv/releases/tag/0.12.20) ⭐️ 5.0/10

uv 0.12.20이 2026-09-28에 출시되어, 의미적으로 동등한 의존성 선언에 대한 잠금 파일 재사용과 CRLF 셔뱅이 있는 휠 스크립트의 두 번째 줄 인코딩 선언 보존을 도입했습니다. 또한 pylock.toml 및 tool-install-locks 관련 여러 미리 보기 기능과 다양한 버그 수정이 포함됩니다. 이번 릴리스는 의미적으로 동등한 선언에 대해 잠금 파일을 재사용하여 불필요한 재해석을 줄임으로써 uv 사용자의 재현성과 성능을 개선합니다. pylock.toml에 대한 미리 보기 지원 확대는 uv가 떠오르는 PEP 751 표준에 맞춰가고 있음을 보여주며, 이는 Python 생태계의 상호운용성에 중요합니다. 주목할 만한 미리 보기 기능으로는 정규화된 요구사항 선언을 작성하는 lockfile-normalization, pylock.toml에서 합성 기본 그룹 인정, 출력 파일 기준 로컬 경로 해석, 반복되는 tool-install-locks 요구사항의 중복 제거가 있습니다. 또한 이번 릴리스는 ext4 파일시스템의 캐시 재검증 지연 조사를 위해 이전 HTTP 캐시 쓰기 스케줄링을 복원했으며, 관리형 Python 경로 및 비-ASCII 요구사항과 관련된 여러 패닉을 수정했습니다.

## [왜 소프트맥스 입력을 하나 줄이지 않는가?](https://www.reddit.com/r/MachineLearning/comments/1wt1mk0/why_not_just_have_one_less_feature_before_softmax/) ⭐️ 5.0/10

Reddit 게시물에서 softmax 출력의 합이 1인 제약을 활용하여 마지막 로짓을 도출함으로써 softmax의 입력 수를 줄이고, 최종 레이어에서 한 세트의 파라미터를 제거하는 것이 유익한지 질문합니다. 이 이론적 질문은 신경망 매개변수화의 중복성을 탐구합니다. 적용할 경우 모델 크기를 약간 줄이고 잠재적으로 수렴을 개선할 수 있지만, 실질적인 이점은 미미할 가능성이 큽니다. 이 접근법은 로짓의 합이 0(또는 다른 상수)이라고 가정하여 마지막 로짓이 다른 로짓의 합의 음수가 되도록 합니다. 이는 softmax 출력에 이미 존재하는 N-1 자유도를 활용하여 입력 파라미터를 줄입니다.

reddit · r/MachineLearning · /u/Kinexity · 9월 29일 05:26

**배경**: 소프트맥스 함수는 실수 벡터(로짓)를 N개 클래스에 대한 확률 분포로 변환합니다. 확률의 합이 1이므로 출력은 N-1의 자유도만 가집니다. 게시물은 로짓에 합이 0인 제약을 부과하여 마지막 로짓을 다른 로짓으로부터 계산할 수 있으며, 이를 통해 소프트맥스 이전의 선형 레이어에서 불필요한 파라미터를 제거할 수 있다고 제안합니다.
