## [Jev: TypeSafe AI의 System One 결정 모델, 빠르고 저렴한 구조화된 출력](https://simonwillison.net/2026/Sep/21/jev/) ⭐️ 8.0/10

TypeSafe AI가 첫 번째 System One 모델인 Jev를 공개했습니다. Jev는 텍스트 입력을 받지만 텍스트를 생성하는 대신 범주, 예/아니오 답변, 평점 및 신뢰도 점수에 대한 부동 소수점 숫자를 반환합니다. 가격은 입력 토큰 100만 개당 0.042달러이며 출력은 무료로, 기존 LLM보다 빠르고 저렴합니다. 이는 분류 및 결정 작업에 최적화된 새로운 범주의 LLM을 도입하여, 텍스트를 파싱하지 않고 신뢰할 수 있는 구조화된 출력을 가능하게 함으로써 AI 애플리케이션 설계를 변화시킬 잠재력이 있습니다. 스팸 탐지, 라벨링, 검색 재순위화 같은 작업에서 AI 비용을 낮출 수 있습니다. Jev는 세 가지 질문 유형을 지원합니다: Noul(베르누이 분포 기반 예/아니오), Choice(확률 분포와 함께 옵션 중 선택), Score(연속 범위 내에서 숫자 평점). API는 단일 입력 상태에서 여러 질문을 병렬로 처리하며, 출력은 무료입니다.

## [Cloudflare Python Workers 일반 공개](https://simonwillison.net/2026/Sep/21/cloudflare-python-worker/) ⭐️ 7.0/10

Cloudflare는 2년간의 미리 보기 기간을 거쳐 Python Workers를 이제 일반 제공한다고 발표하여 Python을 자사의 서버리스 플랫폼에서 일급 지원 언어로 만들었습니다. 이 구현은 Pyodide를 통해 Python을 WebAssembly로 컴파일하고 workerd 런타임에서 실행합니다. 이번 발표는 Python을 Cloudflare의 엣지 컴퓨팅 플랫폼에서 일급 언어로 도입하여 더 많은 Python 개발자에게 생태계를 확장한다는 점에서 중요합니다. 이를 통해 Workers의 성능과 글로벌 분산 배포를 활용하여 엣지에서 서버 측 Python 코드를 실행할 수 있습니다. 주목할 만한 제한 사항으로는 WebAssembly VM에서 multiprocessing과 threading이 작동하지 않는다는 점이 있습니다. 로컬 개발 도구인 pywrangler(PyPI에서 workers-py로 혼동되기 쉽게 패키징됨)는 123MB의 workerd 바이너리를 사용하여 스택의 전체 로컬 시뮬레이션을 실행합니다.

rss · Simon Willison · 9월 21일 22:25

**배경**: Cloudflare Workers는 Google의 JavaScript 엔진인 V8 기반으로 실행되는 서버리스 플랫폼입니다. Pyodide는 WebAssembly 기반의 Python 배포판으로 브라우저와 Node.js에서 동작하며, CPython을 포팅하여 Python 패키지를 해당 환경에서 실행할 수 있게 합니다. workerd는 Workers를 구동하는 Cloudflare의 오픈소스 JavaScript/Wasm 런타임입니다. 현재 WebAssembly에는 내장된 스레드 지원이 없기 때문에 이 구현에서는 multiprocessing과 threading을 사용할 수 없습니다.

## [Jev의 캘리브레이션 갭은 다른 LLM보다 크지만 자율성은 더 높아](https://www.reddit.com/r/MachineLearning/comments/1wmre0b/jevs_calibration_was_measured_the_llms_won_d/) ⭐️ 6.0/10

벤치마크 비교 결과, Jev는 yes/no 작업에서 캘리브레이션 갭이 5.0으로 Gemini 3.8, DeepSeek 2.8, GLM 12.9보다 높지만, 86%의 yes/no 결정을 인간 개입 없이 자율적으로 처리합니다. 이는 캘리브레이션(신뢰도와 정확도의 일치 정도)과 결정 커버리지(모델이 단독으로 처리할 수 있는 결정의 수) 사이의 근본적인 트레이드오프를 강조합니다. 완벽한 캘리브레이션보다 자율성이 더 중요한 애플리케이션에서는 Jev의 접근 방식이 더 선호될 수 있습니다. Jev는 RLCD(Reinforcement Learning for Calibrated Decisions)를 사용하여 훈련되었으며, 생성된 텍스트 대신 확률이 포함된 경계 결정을 반환하는 System One 모델로 설계되었습니다. 벤치마크는 yes/no, pick-one, rubric 세 가지 작업 유형에서 캘리브레이션 갭을 측정했으며, Jev는 모든 유형에서 더 나쁜 점수를 기록했지만 yes/no 작업에서 95% 정확도와 86% 자율 결정 커버리지를 달성했습니다.

reddit · r/MachineLearning · /u/frappuccinoCoin · 9월 21일 22:20

**배경**: 캘리브레이션 갭은 모델이 표시하는 신뢰도와 실제 정확도 간의 차이를 측정하며, 갭이 낮을수록 모델의 신뢰도가 현실을 더 잘 반영합니다. Jev는 TypeSafe AI의 특화된 결정 모델로, 자유 형식 텍스트를 생성하는 범용 LLM과 달리 RLCD를 사용하여 구조화된 작업에 대해 보정된 결정을 내립니다. 이 벤치마크는 Jev를 Gemini, DeepSeek, GLM과 같은 인기 LLM과 캘리브레이션 및 결정 커버리지 측면에서 비교합니다.
