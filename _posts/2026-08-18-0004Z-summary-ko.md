## [Rust, LLVM 기반 GPU 오프로드 기능 도입](https://arxiv.org/abs/2608.13759) ⭐️ 8.0/10

새 논문에서 NVIDIA와 AMD GPU를 위한 네이티브 코드를 생성하는 LLVM Offload 인프라를 사용하여 Rust 컴파일러(rustc)에 직접 통합된 크로스 벤더 GPU 오프로드 인터페이스를 제시했습니다. 향후 Intel 및 Apple 대상도 지원할 예정입니다. 이 접근 방식은 외부 바인딩의 필요성을 없애고 Rust 코드가 GPU에서 직접 실행될 수 있도록 합니다. 이 연구는 Rust GPU 생태계의 큰 격차를 해소하여, 개발자가 번거로운 바인딩을 유지하지 않고도 Rust로 고성능 GPU 코드를 훨씬 쉽게 작성할 수 있게 합니다. 시스템 프로그래밍, AI/ML 추론, HPC에 특히 적합하며, 계산 집약적 도메인에서 Rust 채택을 가속화할 수 있습니다. 이 구현은 nightly Rust의 실험적인 `std::offload` 모듈의 일부로, LLVM Offload 인프라를 사용하여 NVIDIA용 PTX와 AMD용 HIP를 생성합니다. CPU와 GPU 간의 자동 데이터 이동이 계획되어 있으며, 이후 더 세밀한 제어를 위한 선택적 unsafe 인터페이스도 제공될 예정입니다.

hackernews · linggen · 8월 17일 17:54 · [토론](https://news.ycombinator.com/item?id=49334991)

**배경**: GPU 오프로드는 CPU 프로그램에서 GPU로 계산 집약적 코드를 실행하는 기술입니다. 전통적으로 Rust 개발자는 외부 바인딩(예: CUDA 바인딩, Rust-GPU)에 의존하거나 CUDA C++나 OpenCL 같은 GPU 전용 언어를 배워야 했습니다. LLVM Offload 인프라는 이미 Clang/C++에서 사용되며, 여러 GPU 아키텍처를 위한 코드를 컴파일하는 벤더 중립적인 방법을 제공합니다. 이 논문은 동일한 기능을 Rust에 직접 가져와 rustc에 통합합니다.
