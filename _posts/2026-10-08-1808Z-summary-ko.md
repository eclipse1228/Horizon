## [API 벤치마크 데이터 유출 방지를 위한 모범 사례](https://www.reddit.com/r/MachineLearning/comments/1x0o8de/best_practices_when_running_a_benchmark_on_online/) ⭐️ 6.0/10

한 Reddit 사용자가 커뮤니티에 저자원 언어를 위한 머신러닝 모델을 API로 평가할 때 벤치마크 데이터 유출을 방지하기 위한 모범 사례를 질문했습니다. 이 사용자는 Google 및 OpenAI와 같은 제공자가 유료 계정을 사용하더라도 입력 데이터를 학습에 사용하지 않을 것이라고 신뢰할 수 있는지 의문을 제기합니다. 데이터 유출은 벤치마크 결과를 무효화하여 모델이 실제보다 더 우수해 보이게 만들 수 있으며, 이는 실무자와 연구자에게 잘못된 정보를 제공합니다. 이러한 우려는 모든 데이터 포인트가 소중하고 유출이 평가의 무결성을 심각하게 훼손할 수 있는 저자원 언어에서 특히 중요합니다. 사용자는 로컬에서 실행되는 모델은 이 문제를 피할 수 있지만, API 전용 모델의 경우 입력 데이터가 외부 서버로 전송된다고 지적합니다. 온라인 모델을 평가하면서 입력 데이터 통제권을 잃지 않는 확립된 방법이 있는지, 그리고 유료 계정이 학습 데이터 사용에 대한 진정한 보장을 제공하는지 질문합니다.

reddit · r/MachineLearning · /u/neuralbeans · 10월 8일 11:15

**배경**: 머신러닝에서 데이터 유출은 테스트 세트의 정보가 의도치 않게 학습 세트에 유입되어 성능 평가가 지나치게 낙관적으로 나오는 현상을 말합니다. API로 접근 가능한 모델의 경우, 사용자는 제공업체가 제출된 데이터를 향후 학습에 사용하지 않을 것이라고 신뢰해야 하지만, 이러한 정책은 다양하고 검증하기 어렵습니다. 저자원 언어는 레이블이 지정된 데이터가 부족하여 유출이 특히 해로운데, 오염되지 않은 평가 자료 풀이 더욱 줄어들기 때문입니다. 더 넓은 맥락에서 많은 최첨단 모델이 유료 API를 통해서만 제공되므로 사용 편의성과 벤치마크 무결성 사이에 긴장이 발생합니다.
