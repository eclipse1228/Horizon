## [Emacs 31, Tree-sitter 기반 Markdown-ts-mode 내장 도입](https://rahuljuliato.com/posts/markdown-ts-mode-emacs-31) ⭐️ 7.0/10

Emacs 31에는 tree-sitter를 사용하여 고성능 파싱 및 하이라이팅을 제공하는 새로운 내장 Markdown-ts-mode가 포함되었습니다. CommonMark와 GFM(GitHub Flavored Markdown)을 모두 지원하며, 현재 실험 단계로 사용자가 직접 활성화해야 합니다. 이는 Markdown을 사용하는 Emacs 사용자에게 외부 패키지 없이 더 나은 성능과 정확한 구문 강조를 제공하는 중요한 개선입니다. 또한 Neovim, Helix, Zed에서 이미 사용 중인 tree-sitter를 활용함으로써 Emacs가 현대 편집기 트렌드에 발맞추게 되었습니다. 이 모드는 CommonMark 사양과 GFM 기능(예: 작업 목록 `- [ ]`, 취소선 `~~text~~`)을 기본 지원합니다. 실험적 기능이므로 사용자는 설정에 `(require 'markdown-ts-mode)`를 추가하여 수동으로 로드해야 합니다.

hackernews · RahulMJ · 8월 27일 13:22 · [토론](https://news.ycombinator.com/item?id=49464543)

**배경**: Tree-sitter는 소스 파일에 대한 구체적인 구문 트리를 구축하는 증분 파싱 라이브러리로, 코드 편집 시 효율적인 실시간 업데이트를 가능하게 합니다. 원래 GitHub에서 Atom 편집기를 위해 개발되었으며, 현재 Neovim, Helix, Zed와 같은 편집기에 통합되어 있습니다. CommonMark는 2014년에 원래 Markdown 설명의 모호성을 해결하기 위해 만들어진 표준화된 Markdown 사양이며, GFM은 여기에 GitHub 특화 기능을 추가한 것입니다.

Organic Maps와 Maps.Me에서 포크된 오픈소스 내비게이션 앱 CoMaps이 광범위한 FLOSS(자유 및 오픈소스 소프트웨어) 생태계와의 통합을 발표했습니다. 이번 조치는 OpenStreetMap(OSM) 데이터 품질을 개선하고 공유 커뮤니티 서비스를 촉진하는 것을 목표로 합니다. 이번 통합은 OSM 데이터와 공유 서비스에 대한 협업을 장려함으로써 FLOSS 매핑 생태계를 강화하며, Google Maps와 같은 독점 플랫폼에 대한 프라이버시를 존중하는 대안을 제공합니다. 이는 상업적 지도 서비스의 지배력을 줄이고 커뮤니티 주도의 공개 지리 데이터를 촉진할 수 있습니다. CoMaps는 OSM 데이터를 기반으로 완전한 오프라인 지도를 제공하며 위치 추적이나 광고가 없으며, 2025년 7월 iodéOS의 기본 지도 앱으로 선정되었습니다. 이번 통합은 기본 OSM 데이터 세트를 개선하고 API를 갖춘 POI/즐겨찾기 데이터베이스 및 실시간 교통 데이터 서비스와 같은 공유 서비스를 개발하는 데 중점을 둡니다.

## [Microduck: Pollen Robotics의 작은 로봇 오리](https://pollen-robotics.com/microduck/) ⭐️ 5.0/10

Pollen Robotics가 작은 로봇 오리인 Microduck을 발표하고 온라인 시뮬레이터를 출시했습니다. 시뮬레이터는 처음에 AZERTY 키보드 레이아웃에 따른 ZQSD 키를 사용합니다. Microduck은 취미 로봇 공간에서 재미있는 제품으로, MuJoCo 기반 시뮬레이터는 로봇 강화 학습에서 물리 엔진 사용이 증가하고 있음을 보여줍니다. 키보드 레이아웃 논의는 전 세계 사용자를 위한 접근성 문제를 제기합니다. 시뮬레이터는 Google DeepMind가 유지 관리하는 오픈 소스 물리 엔진 MuJoCo에서 실행됩니다. 댓글 작성자 lambda는 기본 키 바인딩이 WASD(QWERTY)가 아닌 ZQSD(AZERTY)여서 프랑스어 사용자가 아닌 사람들에게 혼란을 줄 수 있다고 지적했습니다.

hackernews · robotswantdata · 8월 27일 10:57 · [토론](https://news.ycombinator.com/item?id=49462763)

**배경**: MuJoCo(Multi-Joint dynamics with Contact)는 접촉이 있는 강체 동역학을 시뮬레이션하는 물리 엔진입니다. 실제 로봇에 배포하기 전에 시뮬레이션에서 강화 학습 정책을 훈련하는 데 널리 사용됩니다. Pollen Robotics는 Reachy와 같은 인터랙티브 로봇을 전문으로 하는 프랑스 회사입니다.
