## [1024바이트 C 코드로 만든 Python 인터프리터](https://austinhenley.com/blog/python1024.html) ⭐️ 7.0/10

한 개발자가 1024바이트의 C 소스 코드만으로 최소한의 Python 인터프리터를 만들었으며, for, while, if 및 기본 산술 연산을 포함한 아주 작은 언어 부분집합을 지원합니다. 이 프로젝트는 극단적인 코드 골프와 미니멀리즘 프로그래밍을 보여주며, 매우 적은 코드로도 얼마나 많은 것을 할 수 있는지 입증하여 교육 및 임베디드 시스템 분야에 영감을 줍니다. 이 인터프리터는 입력의 정확성에 대해 많은 가정을 합니다. 예를 들어, 'f' 키워드는 무조건 'for [x] in range[y]' 구문이라고 가정하며 오류 검사를 하지 않습니다. C 코드가 작은 바이너리로 컴파일되는 것은 아니며, 훨씬 더 큰 실행 파일로 컴파일됩니다.

**배경**: 코드 골프는 주어진 문제를 해결하기 위해 가능한 가장 짧은 소스 코드를 작성하는 레크리에이션 프로그래밍 대회입니다. 이 프로젝트는 일반적인 알고리즘 퍼즐이 아닌 프로그래밍 언어 인터프리터 구현에 코드 골프를 적용한 극단적인 예시입니다. 목표는 생산 가능한 소프트웨어를 만드는 것이 아니라 간결함과 창의적인 프로그래밍의 한계를 탐구하는 데 있습니다.

## [PINNStudio: 물리 정보 신경망을 위한 무료 오픈소스 노코드 GUI](https://www.reddit.com/r/MachineLearning/comments/1w9a2i7/pinnstudio_a_free_opensource_nocode_gui_for/) ⭐️ 7.0/10

PINNStudio는 새로 출시된 무료 오픈소스 그래픽 사용자 인터페이스로, 사용자가 별도의 보일러플레이트 코드를 작성하지 않고도 물리 정보 신경망을 설정, 학습 및 시각화할 수 있습니다. DeepXDE를 기반으로 코드를 자동 생성하며, 열 방정식, Allen-Cahn, Cahn-Hilliard와 같은 고전적인 편미분 방정식 템플릿을 내장하고 있습니다. 이 도구는 PINN 사용의 진입 장벽을 크게 낮춰 코딩 경험이 부족한 학생과 연구자도 과학적 머신러닝을 실험할 수 있게 합니다. 또한 반복적인 코딩 작업을 없애 숙련된 사용자의 워크플로우를 가속화합니다. PINNStudio는 1D 및 2D 영역, 정방향 및 역문제, 사용자 정의 네트워크 아키텍처 및 학습 일정을 지원하며, 앱 내에서 실시간 손실 곡선과 솔루션 플롯을 제공합니다. pip install pinnstudio로 설치할 수 있으며 GitHub에 호스팅되어 있습니다.

reddit · r/MachineLearning · /u/Impossible-Jello2749 · 9월 6일 22:19

**배경**: 물리 정보 신경망(PINN)은 일반적으로 편미분 방정식(PDE)으로 표현되는 물리 법칙을 학습 과정에 통합하는 딥러닝 모델의 한 종류입니다. 과학적 머신러닝(SciML)은 물리 기반 모델링과 데이터 기반 접근 방식을 결합하여 공학 및 과학의 복잡한 문제를 해결합니다. 전통적으로 PINN을 설정하려면 PDE, 경계 조건 및 네트워크 아키텍처를 정의하기 위해 상당한 코딩 작업이 필요합니다.
