## [LLM 0.32: Reasoning traces, server-side tools, OpenAI Responses](https://simonwillison.net/2026/Aug/4/new-release-of-llm/#atom-everything) ⭐️ 8.0/10

LLM 0.32, a major update to the open-source CLI tool, adds visible reasoning traces for models, server-side provider tools (e.g., OpenAI CodeInterpreter and WebSearch), redesigned content-addressable SQLite logs, and support for the OpenAI Responses API and GPT-5.6 model family. This release significantly enhances transparency and utility for LLM users, allowing them to inspect model reasoning and leverage server-side capabilities like code execution and web search directly from the CLI. It also positions LLM as a more powerful and flexible tool for AI practitioners, integrating cutting-edge API features. Reasoning traces are displayed to stderr by default, with a -R/--hide-reasoning flag to suppress them. The new default model is GPT-5.6 Luna, and the llm openai endpoint command allows one-off prompts against any OpenAI-compatible endpoint without logging. The llm-anthropic plugin adds WebSearch, WebFetch, CodeExecution, and AnthropicMCP tools.

rss · Simon Willison · Aug 4, 23:58

**Background**: LLM is a popular open-source command-line tool by Simon Willison for interacting with large language models (LLMs) from the terminal. It supports multiple providers via plugins and logs all interactions to a SQLite database. Reasoning traces are the internal chain-of-thought steps a model generates before producing a final answer, which are often hidden from users. Server-side tools are capabilities provided by the API provider (e.g., code execution, web search) that the model can invoke during a conversation.

## [Munich Funds libexpat Maintainer for 6-Month Open Source Sabbatical](https://blog.hartwork.org/posts/libexpat-city-of-munich-open-source-sabbatical/) ⭐️ 7.0/10

The City of Munich is funding Sebastian Pipping, the maintainer of the libexpat XML parser library, for up to six months through its Open Source Sabbatical program. This marks the first time the program has been filled, allowing Pipping to focus on improving libexpat. This is a significant step for open-source sustainability, as a municipal government directly funds a critical but under-resourced library maintainer. It sets a precedent for other cities and organizations to support the digital infrastructure they rely on. The sabbatical is open to both internal and external developers, and the selection is based on proposals for bug fixes or features for open-source projects used by Munich. libexpat is installed on at least 2,700 Linux servers within the city alone, highlighting its widespread use.

## [Bad Apple Video Compressed into 3MB Neural Network](https://www.reddit.com/r/MachineLearning/comments/1vfrco1/i_compressed_bad_apple_into_a_3mb_neural_network_p/) ⭐️ 7.0/10

A developer trained a small multilayer perceptron (MLP) with sine activations (SIREN) to memorize the entire Bad Apple animation, compressing about 2.7 billion pixels into only 790,000 parameters (3.2 MB in float32). The network takes 3D coordinates (time, y, x) and outputs a grayscale pixel value, effectively storing the video implicitly in its weights. This project demonstrates a practical application of implicit neural representations (INRs) for video compression, achieving a high compression ratio with reasonable visual quality. It also highlights effective training techniques—such as time-stretching and motion-focused sampling—that overcome common limitations of SIREN networks when handling temporal data. The network uses 5 linear layers with sine activations, 512 hidden units, ω₀=30, and a sigmoid output. The original video was subsampled to 1620 frames at 384×384 resolution, and the time coordinate was scaled by 4× relative to space to improve temporal capacity; half of each training batch was drawn from pixels that changed between neighboring frames.

reddit · r/MachineLearning · /u/Which_Lie_8932 · Aug 5, 00:01

**Background**: Implicit neural representations (INRs) are a class of neural networks that parameterize continuous signals—such as images, audio, or video—directly as the weights of a multilayer perceptron (MLP). SIREN (Sinusoidal Representation Network) uses periodic sine activation functions instead of traditional ReLU, enabling the network to represent high-frequency details more effectively. Another common approach is to use Fourier feature mappings to help MLPs learn high-frequency functions. This project applies INR techniques to video compression, storing an entire animation implicitly in a small network.

## [Centering Divs Against the Browser Window: A CSS Experiment Draws Fire](https://seg6.space/posts/center-div/) ⭐️ 6.0/10

A technical blog post at seg6.space presents a CSS/JavaScript technique to center a div relative to the entire browser window rather than the viewport. Community testing reveals the approach behaves inconsistently across Firefox and Edge, especially when sidebars are open, often causing content to shift or be covered. This touches on a niche but real frontend problem: browser UI sidebars (bookmarks, vertical tabs) shrink the actual viewport, and most CSS centering ignores this. The discussion highlights why 'clever' workarounds often break in practice, reinforcing the industry trend toward standard, predictable layout methods. The technique reportedly relies on browser reporting window dimensions beyond the viewport, and uses JavaScript to adjust after rendering, producing a visible flicker. Testers found random behavior: sometimes the sidebar covers content, sometimes content shifts off-screen, and results vary between Firefox and Edge (including sticky vs collapsed sidebars).

hackernews · seg6 · Aug 4, 22:24 · [Discussion](https://news.ycombinator.com/item?id=49176055)

**Background**: Centering a div is a classic CSS challenge, commonly solved with flexbox (justify-content/align-items), CSS grid, or absolute positioning plus transform: translate(-50%, -50%). In normal use, elements are centered relative to the viewport, which is the visible area inside the browser window. However, browser UI elements such as bookmarks sidebar or vertical tabs reduce that visible area; the article instead tries to center relative to the whole browser window, a distinction most CSS layouts ignore.
