## [독점 LLM에서 추론 흔적을 훔치는 기술](https://stolen-thoughts.com/) ⭐️ 8.0/10

연구진이 프런티어 모델에서 추론 흔적을 포착한 뒤, 이를 더 약한 자매 모델에 재생하고 해당 약한 모델을 탈옥(jailbreak)하여 원래 추론 단계를 추출함으로써 독점 LLM API로부터 추론 흔적을 훔치는 방법을 개발했습니다. 이 기술은 모델 계열 간 추론 흔적 처리 방식의 중대한 보안 취약점을 드러내며, 독점 모델 기능의 무단 증류를 가능하게 하여 지적 재산권과 경쟁 우위에 대한 심각한 우려를 제기합니다. 이 공격은 동일 계열 내 모델 간 추론 흔적의 이식성을 악용합니다. 약한 모델을 탈옥하여 강한 모델이 숨겼을 추론 내용을 드러낼 수 있으며, API 보호 조치를 우회합니다.

**배경**: 추론 흔적은 대규모 언어 모델이 최종 답변을 생성하기 전 단계별로 생성하는 사고 사슬(chain-of-thought) 출력입니다. 탈옥은 적대적 프롬프트를 사용하여 모델의 안전 장치를 우회하는 것을 말합니다. 모델 증류는 더 큰 '교사' 모델의 출력을 바탕으로 더 작은 '학생' 모델을 훈련하는 방식이며, 허가 없이 수행되면 지적 재산권 도용의 한 형태가 됩니다. 제시된 기술은 이러한 개념들을 결합하여 추론 흔적의 이식성과 약한 모델의 탈옥을 활용함으로써 무단 증류를 달성합니다.

## [Apple Silicon macOS VM: GPU 패스스루 수정으로 LLM 추론 11–16배 가속](https://github.com/trycua/cua/blob/main/blog/gpu-passthrough-macos-vms.md) ⭐️ 7.0/10

Apple의 Virtualization.framework를 사용하는 macOS VM에서 GPU 패스스루를 수정하여 잘못된 GPU 커널이 선택되던 문제를 바로잡아 llama.cpp의 LLM 추론 속도를 11~16배 향상시켰습니다. 이 발견은 macOS 가상화 환경에서 AI 워크로드의 주요 성능 병목을 드러냈으며, 수정을 통해 VM 내에서 GPU 기능을 올바르게 노출하면 거의 네이티브에 가까운 추론 속도를 얻을 수 있음을 보여줍니다. 이는 macOS VM에서 LLM을 실행하는 개발자, 특히 통제된 환경에서 테스트하거나 배포하는 경우에 중요합니다. 이 수정은 Virtualization.framework VM이 llama.cpp로 하여금 잘못된 GPU 커널을 선택하게 하여 성능이 저하되던 문제를 구체적으로 해결합니다. 성능 향상은 이 특정 VM 환경에 국한되며, 네이티브 macOS나 다른 가상화 솔루션에는 적용되지 않습니다.

hackernews · frabonacci · 8월 11일 14:50 · [토론](https://news.ycombinator.com/item?id=49259339)

**배경**: Apple의 Virtualization.framework는 Apple Silicon 및 Intel Mac에서 VM을 생성하고 관리하기 위한 API를 제공합니다. macOS나 Linux 게스트를 실행할 수 있지만, 게스트에는 가상 그래픽 장치가 제공되어 호스트 GPU의 모든 기능을 보고하지 못할 수 있습니다. llama.cpp는 대규모 언어 모델을 위한 인기 있는 오픈소스 추론 엔진으로, Apple Silicon에서 Metal을 통해 GPU 가속을 지원합니다. GPU 커널 선택은 성능에 매우 중요하며, VM의 제한된 Metal 프로필로 인해 llama.cpp가 차선의 커널을 사용하게 될 수 있습니다.

## [LLM 에이전트가 1v1 축구로 겨루는 'Agentic World Cup'](https://www.reddit.com/r/MachineLearning/comments/1vllvmn/we_built_the_agentic_world_cup_llms_that_compete/) ⭐️ 6.0/10

Agentic World Cup는 사용자가 LLM 기반 에이전트를 프롬프트로 '코칭'해 제출하면, 다른 에이전트와 시뮬레이션 1v1 축구 경기에서 자동으로 겨루는 새 플랫폼입니다. 매주 최종 순위가 공개됩니다. 이 프로젝트는 LLM이 텍스트 기반 작업에는 뛰어나지만 신체적 이해나 운동 추론이 부족하다는 '구현 격차(embodiment gap)'를 겨냥합니다. 성공할 경우 연구자뿐 아니라 일반인도 사용할 수 있는 공개적인 스포츠 기반 구현 지능 벤치마크가 될 수 있습니다. 사용자는 LLM을 선택하고 프롬프트로 코칭한 뒤 제출하면, 에이전트가 자동으로 다른 에이전트와 경기하며 최종 순위가 사이트에 공개됩니다. 이 플랫폼은 Reddit에 작업 중인 프로젝트로 발표되었으며, 스포츠를 구현 지능 과제의 '정점'으로 보고 ViT, 온라인 RL, 신경-기호 시스템 등 다양한 방법을 시험해볼 수 있는 공개 포럼을 목표로 합니다.

**배경**: 구현 지능(Embodied AI) 연구는 AI 에이전트에게 물리적 기반을 부여하는 것을 목표로 하며, EmbodiedBench 같은 벤치마크는 멀티모달 LLM을 구현 에이전트로 평가합니다. 역사적으로 다중 에이전트 로봇 축구는 조정과 실시간 의사결정을 시험하는 고전적인 테스트베드였으며, Agentic World Cup은 현대 LLM을 '선수'로 삼아 이 아이디어를 발전시킵니다. '구현 격차'는 AI의 추상적 지식과 물리적 환경에서의 행동·추론 능력 사이의 간극을 뜻합니다.
