## [uv 0.12.14, HTTP Range 다운로드 재개 및 오류 진단 개선](https://github.com/astral-sh/uv/releases/tag/0.12.14) ⭐️ 5.0/10

uv 0.12.14(2026-09-15 출시)는 HTTP Range 기반 중단된 다운로드 재개 기능을 추가하고, 일관된 힌트와 라벨링된 원인 체인으로 오류 진단을 개선했으며, 예상 실패(1)와 운영/내부 실패(2)를 구분하도록 종료 코드를 개선했습니다. 이번 릴리스는 중단된 다운로드를 재개하여 불안정한 네트워크 사용자의 신뢰성을 높이고, 더 명확한 오류 메시지와 종료 코드로 개발자 경험을 개선합니다. 이러한 점진적 개선은 uv가 빠르고 현대적인 Python 패키지 관리자로서의 입지를 강화합니다. 주요 개선 사항으로는 HTTP Range 기반 다운로드 재개, 실패한 'uv tool upgrade'에 대한 리졸버 힌트, 공유 잠금 파일에서 여러 종속성 선택을 내보내는 'batch-export' 미리보기 기능이 있습니다. 성능 개선은 로컬 wheelhouse 및 대형 인덱스에서 종속성 해석을 가속화하고, 버그 수정은 Windows 긴 경로 문제와 Python 심볼릭 링크 처리를 해결합니다.
