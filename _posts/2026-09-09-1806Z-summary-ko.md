## [uv 0.12.12, 코드 서명 추가 및 exclude-newer 버그 수정](https://github.com/astral-sh/uv/releases/tag/0.12.12) ⭐️ 5.0/10

uv 0.12.12는 macOS 및 Windows 실행 파일에 Apple Developer ID와 Azure Artifact Signing을 사용한 코드 서명을 도입하고, exclude-newer 기준일 이후에 업로드된 배포판이 lockfile에 잘못 포함되던 버그를 수정했습니다. 코드 서명을 통해 사용자가 uv 바이너리의 게시자와 무결성을 확인할 수 있어 보안 경고와 오탐(false positive)이 줄어듭니다. exclude-newer 수정으로 lockfile이 기준일을 올바르게 준수하여 의도치 않은 종속성 업데이트를 방지합니다. macOS 실행 파일은 Apple Developer ID 인증서로 서명되고 공증(notarized)되며, Windows 실행 파일은 Azure Artifact Signing을 통해 타임스탬프가 포함된 Authenticode 서명을 받습니다. 버그 수정은 exclude-newer 기준일 이후에 업로드된 배포판이 lockfile 및 요구사항 해시에서 제외되지 않던 문제(#21539)를 해결합니다.
